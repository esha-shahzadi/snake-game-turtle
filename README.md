# Colorful Star Pattern using Python Turtle

A Python program that draws a colorful, animated star-like spiral pattern on a black background using the turtle graphics library.

## What it does
- Creates a black drawing window using turtle
- Changes the color smoothly at every step using the colorsys module (HSV to RGB)
- Repeats 200 times, drawing lines, turning at fixed angles and drawing circular arcs
- Produces a colorful spiral pattern that looks like a star

## Tools Used
- Python
- turtle (built-in library)
- colorsys (built-in library)

## How to run
1. Install Python from python.org
2. Download `Colour Stars.py`
3. Run in terminal or command prompt:
   ```
   python "Colour Stars.py"
   ```
4. A window will open and the pattern will be drawn automatically

## Concepts Practiced
- Loops
- Color models (HSV and RGB)
- Basic graphics programming
